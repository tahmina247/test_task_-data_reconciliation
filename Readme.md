# Reconciliation Project

## Описание

Это тестовое задание по сверке данных между двумя отчетами:

* **RpaBank_report**
* **Pindodo_report**

Программа читает данные из текстовых файлов, парсит их и сохраняет в Excel файлы.
После этого выполняется сверка данных между двумя отчетами.

Результат сверки сохраняется в отдельный Excel файл.

---

## Используемые библиотеки

* pandas — для работы с таблицами и Excel
* loguru — для логирования
* re — для парсинга строк

---

## Как запустить программу

### Вариант 1 (если установлен Python)

1. Установить зависимости:

pip install pandas loguru

2. Запустить файл:

python main.py

---

### Вариант 2 (без Python)

Можно запустить **exe файл**:

dist/main.exe

---

## Входные файлы

Программа использует два текстовых файла:

* RpaBank_report.txt
* Pindodo_report.txt

Они должны находиться в одной папке с программой.

---

## Что делает программа

1. Читает файл **RpaBank_report**

2. Парсит строку на столбцы:

   * Number
   * Index
   * Local DateTime
   * Transaction ID
   * Transaction Amount
   * Currency
   * Card Number
   * Terminal ID

3. Читает файл **Pindodo_report**

В этом файле каждая транзакция записана вертикально.

4. Сохраняет данные в Excel:

   * RPABank_report.xlsx
   * Pindodo_report.xlsx

5. Выполняет сверку данных.

Сравнение выполняется по следующим полям:

* Local DateTime
* Transaction Amount
* Currency
* Card Number
* Terminal ID

---

## Результат

Создается файл:

result.xlsx

В нем есть три листа:

* **Успешные** — записи которые есть в двух отчетах
* **RPABank_неуспешные** — записи только из RpaBank
* **Pindodo_неуспешные** — записи только из Pindodo

---

## Особенности и допущения

* данные в RpaBank_report разделяются с помощью split()
* некоторые столбцы объединены и извлекаются с помощью регулярных выражений
* в Pindodo_report одна транзакция записана несколькими строками
* сверка выполняется через pandas merge
